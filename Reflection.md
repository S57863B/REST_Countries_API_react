Building the REST Countries Single Page Application was a highly rewarding experience that solidified my understanding of React, TypeScript, and modern state management. My development process began with establishing a strict, modular architecture. I prioritized separating business logic from the UI by relying heavily on custom hooks, such as `useCountries` for data fetching and `useFilters` for search and categorization. This kept my React components clean, focused, and highly maintainable.

One of the primary challenges I faced was managing global state without relying on bulky external libraries like Redux. Implementing the "Want to Visit" list required passing state across various nested components. I solved this by utilizing the React Context API, creating a `VisitListContext` that also seamlessly synchronizes with browser `localStorage` to ensure user data persistence across sessions. Another significant challenge was styling the application strictly with pure CSS—a deliberate constraint to avoid frameworks. Ensuring a responsive CSS grid layout, creating smooth glassmorphism hover effects, and building a flawless Dark/Light mode toggle required meticulous attention to CSS variables and structural design principles.

To handle complex nested routing, specifically the requirement to navigate interactively between bordering countries, I mapped the raw `alpha3Code` array back to the main dataset to dynamically generate user-friendly functional links. Furthermore, to optimize rendering performance and avoid redundant data fetching, I implemented a simple but effective module-level caching system within my data-fetching hook.

Looking forward, there are several potential improvements I would like to implement. Because the country dataset is relatively large, introducing list virtualization to the main dashboard grid would greatly enhance DOM performance. Additionally, I aim to integrate comprehensive unit testing using Jest and React Testing Library to ensure my custom hooks and context providers remain robust as the application scales. Overall, this project drastically improved my architectural planning and front-end capabilities.
